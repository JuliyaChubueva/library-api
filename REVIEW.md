# Саморевью API-контракта

Самопроверка выполнена по чек-листу урока 3.

## 1. Ресурсы и URL

- [x] URL используют существительные во множественном числе:
  `/books`, `/readers`, `/loans`.
- [x] Используется kebab-case.
- [x] Глагольные URL отсутствуют, кроме осознанного действия
  `/loans/{id}/return`.
- [x] ID конкретного ресурса передаётся в path.
- [x] Фильтры, сортировка и пагинация передаются через query-параметры.
- [x] Версия API указана в servers: `/v1`.

## 2. Методы и HTTP-коды

- [x] POST создания возвращает 201.
- [x] Для созданных ресурсов используется заголовок Location.
- [x] DELETE возвращает 204 без тела.
- [x] Получение одного ресурса возвращает 200 или 404.
- [x] Пустой список должен возвращаться как 200 с пустым массивом data.
- [x] 400 используется для некорректного запроса.
- [x] 409 используется для конфликтов состояния и бизнес-правил.
- [x] 422 используется для ошибок валидации.

## 3. Схемы

- [x] Описаны Book, Reader и Loan.
- [x] Для создания и обновления используются отдельные request-схемы.
- [x] Серверные поля не принимаются от клиента.
- [x] `available_copies` помечен как readOnly.
- [x] `registered_at`, `loaned_at`, `returned_at` контролируются сервером.
- [x] Неизвестные поля запрещены через `additionalProperties: false`.
- [x] Используются ограничения `required`, `minimum`, `minLength`,
  `format` и `enum`.

## 4. Списки

- [x] Коллекции поддерживают фильтрацию.
- [x] Коллекции поддерживают сортировку.
- [x] Коллекции поддерживают пагинацию через `limit` и `offset`.
- [x] `limit` имеет default 20 и maximum 100.
- [x] Ответ списка содержит `data` и `pagination`.
- [x] Просроченные выдачи доступны через
  `GET /loans?status=overdue`.

## 5. Ошибки

- [x] Все ошибки используют единый ErrorResponse.
- [x] Поддерживаются коды:
  `INVALID_REQUEST`,
  `NOT_FOUND`,
  `VALIDATION_ERROR`,
  `CONFLICT`,
  `BUSINESS_RULE_VIOLATION`,
  `IDEMPOTENCY_MISMATCH`.
- [x] ErrorResponse содержит `code`, `message`, `details`, `request_id`.
- [x] Для 422 приведён пример с `details`.

## 6. Бизнес-правила

- [x] Выдача возможна только при `available_copies > 0`.
- [x] У читателя не может быть более 5 активных выдач.
- [x] `due_date` новой выдачи должна быть позже текущей даты.
- [x] Книгу нельзя удалить при наличии активных выдач.
- [x] Читателя нельзя удалить при наличии активных выдач.
- [x] Возврат реализован через `POST /loans/{id}/return`.

## 7. Idempotency-Key

- [x] Заголовок обязателен для `POST /loans`.
- [x] Повтор с тем же ключом и тем же телом возвращает полный replay ответа.
- [x] Повтор с тем же ключом и другим телом возвращает
  `409 IDEMPOTENCY_MISMATCH`.
- [x] Описано поведение конкурентных повторов.
- [x] TTL ключа — 24 часа.

## 8. Документация

- [x] Используются tags Books, Readers и Loans.
- [x] У операций есть summary и description.
- [x] Добавлены примеры успешных ответов и ошибок.
- [x] Общие элементы переиспользуются через `$ref`.
- [x] OpenAPI-файл открывается в Swagger Preview без ошибок.

## 9. Дополнительное задание

- [x] Добавлена Bearer JWT авторизация через `securitySchemes`.

## Итог

Контракт соответствует требованиям задания и чек-листу урока 3.
